# Contributing to Hagere

First off, thank you for taking the time to contribute! Hagere is an open-source civic engagement platform built to empower citizens to participate in government policy discussions, vote transparently, and engage in constructive public discourse.

The following is a comprehensive guide containing the setup instructions, file structures, configuration snippets, and workflows required to contribute to both the backend and frontend.

---

## Code of Conduct

By participating in this project, you agree to abide by our code of conduct. Please report unacceptable behavior or policy violations directly to the project maintainers.

---

## Prerequisites & Initial Setup

Make sure you have the following installed on your local machine:
* **Node.js** (v18+ recommended)
* **npm** or **yarn**
* **MongoDB** (local instance or a MongoDB Atlas connection string)
* **Firebase Project** (for authentication setup)
